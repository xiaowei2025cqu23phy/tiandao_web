## 占卜流程

```
输入问题 → 选择起卦方式（6爻） → 生成本卦 + 变卦 → AI 解卦
```

每一步都有精美的交互动画。支持**铜钱、蓍草（大衍筮法）、数字、米卦、时间**五种起卦方式；成卦后自动排**六爻纳甲盘**（六神、纳甲、六亲、世应、伏神，以占卜当日干支起六神）。

### 起卦法说明

- **铜钱卦**：三枚铜钱六掷，乾面为阳、坤面为阴：三阳为老阳、三阴为老阴、两阳一阴为少阳、两阴一阳为少阴；
- **蓍草卦（大衍筮法）**：依《周易·系辞上》「大衍之数五十，其用四十有九」，三变成一爻、十八变成一卦，四象概率为老阳 3/16、少阳 5/16、少阴 7/16、老阴 1/16；
- **数字卦 / 米卦**：按《梅花易数》先天八卦数（乾一兑二离三震四巽五坎六艮七坤八）取上、下卦，动爻数以 6 取余、余 0 取上爻；
- **时间卦**：以年支序数（立春为界）+ 农历月 + 农历日取上卦，再加时支序数取下卦，总数取动爻（农历由精确查表换算）。

## 八字流程

```
输入出生日期 + 时辰 + 出生地经度 + 性别 → 推算四柱 → 真太阳时 → 五行分析 → 神煞/十二长生 → 大运/流年 → 日主解读
```

### 干支计算的精度说明

- **日柱**以 1900-01-01（甲戌日）为锚点精确推算，与万年历一致；
- **年柱**以立春为界（立春前按上一年计）；
- **月柱**按「五虎遁」配合节气定支，**时柱**按「五鼠遁」；
- **真太阳时**：按出生地经度修正标准时（每 1° = 4 分钟，东经为正，默认 120°E）并叠加当日均时差（视太阳时 − 平太阳时，全年 −14 ~ +16 分钟），总误差一般 ≤ 1-2 分钟；
- **农历**：1900–2100 年闰月与大小月查表**精确转换**（1900-01-31 = 正月初一锚点）；
- **节气**：由天文算法（太阳视黄经牛顿迭代，含章动与光行差）计算，**日期与万年历一致**，时刻误差一般 1-3 分钟、个别约 8 分钟；年柱/月柱/大运起运均以精确交节时刻为界；
- **大运**：以月柱为起点，阳男阴女顺排、阴男阳女逆排，每步 10 年，附十神与起止年份；起运岁数 = 「出生到最近交节时刻的天数 ÷ 3」（四舍五入）；
- **流年**：以公历年份推六十甲子，附十神与吉凶评语（规则化，仅供参考）。
- **神煞**：天乙贵人、文昌贵人、禄神、羊刃、桃花、驿马、华盖（按日干/日支口诀查四柱地支）；
- **十二长生**：日干对年/月/日/时支的十二长生状态（阳干顺行、阴干逆行），月令状态为主；
- **犯太岁**：按年支推值/冲/害/破/刑（辰午酉亥自刑、子卯相刑、寅巳申与丑戌未三刑），附传统化解建议；
- **二十四节气**：24 节气含义、民俗与养生，日期由天文算法计算、与万年历一致（北京时间显示）；
- **传统节日**：以农历查表精确换算日期，支持春节、除夕、端午、中秋等节日倒计时。
- **姓名五格**：81 数理按通行姓名学表；笔画统一按康熙字典计法（部首按康熙计、简体按繁体计）的常用字手写库，未收录汉字按估算并明确提示。
- **适用范围**：农历查表覆盖 1900–2100 年；节气天文算法在该区间内日期精确、时刻一般 1–3 分钟（2050 年后 ΔT 为外推值，时刻误差可能略增）；八字输入超出范围会提示而非静默失败。

## AI 配置

在设置中填入 API Key 即可使用 AI 解卦。支持：

- **Gemini** — Google 免费 API（浏览器直连可用）
- **OpenAI** — GPT-4o（官方 API 默认不允许浏览器跨域直连，建议通过自有代理中转）
- **DeepSeek** — 国产高性价比
- **OpenRouter** — 聚合 API

未配置 AI 也可以正常起卦和查看卦象。API Key 仅保存在浏览器 localStorage 中，请勿在公共设备上使用。

## PWA 离线

应用支持 PWA：可「添加到主屏幕」全屏打开，并注册 Service Worker 做轻量离线缓存（页面壳网络优先、静态资源缓存优先）。首次访问联网后，再次打开或断网时已访问过的功能（占卜、八字、黄历等本地算法）仍可使用；AI 解卦等联网功能在离线时不可用。

```bash
npm test          # 单次运行
npm run test:watch  # 监听模式
```

## 部署上线

纯前端静态应用，无后端依赖，构建产物在 `dist/`，任何静态托管都能跑。

```bash
npm ci && npm run build   # 产物在 dist/
```

**推荐平台（零配置，PWA 友好）**

- **Vercel**：导入仓库即可，已内置 `vercel.json`（SPA 回退 + 静态资源缓存头）；
- **Cloudflare Pages / Netlify**：导入仓库即可，`public/_redirects` 已提供 SPA 回退；
- **GitHub Pages**：已提供 `.github/workflows/deploy.yml`（push 到 master 自动构建部署）。
  注意：仅适用于**根路径**部署（用户站或自定义域名）；项目子路径（`/repo/`）需调整 `base` 与 PWA 路径，见工作流内注释。

**上线前须知**

- 部署地址必须是 **HTTPS**（PWA Service Worker 的要求；`localhost` 除外）；
- 首次联网访问后，本地算法（占卜/八字/黄历/择日等）断网可用；AI 解卦需联网；
- AI API Key 仅保存在浏览器 localStorage（客户端直连），请勿在公共设备上配置；
- 更换部署域名后，`index.html` 中的 `og:image` 建议改为绝对地址。
